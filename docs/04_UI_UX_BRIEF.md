# SkillSense AI — UI/UX Brief

# 1. Design Direction

The interface should feel:

- Modern
- Intelligent
- Educational
- Trustworthy
- Clean
- Data-driven
- Student-friendly

Avoid an overly futuristic "AI gimmick" visual style.

---

# 2. Design Principle

Every screen should answer one of:

- Where am I?
- What am I learning?
- Why am I learning it?
- What should I do next?
- How am I improving?

---

# 15. Responsive Requirements

Must work on:

- Desktop
- Tablet
- Mobile

Mobile navigation should collapse into a menu.

---

# 16. UI States

Every data-driven component should support:

- Loading
- Success
- Empty
- Error
- Disabled
- Retry

---

# 17. Accessibility

Use:

- Semantic HTML
- Keyboard navigation
- Accessible labels
- Adequate contrast
- Focus states
- Form error messages
